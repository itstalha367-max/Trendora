## Phase 5 coverage note

Phase 5 adds or materially completes the mapped Draft Orders, Segments, Product Questions, Promotions, Gift Cards, Affiliates, Navigation, Email Templates, Notification Templates, Purchase Orders, Security Center, Admin Notifications, Domains, Integrations, API Keys/Webhooks and Admin Profile areas. It also adds customer Store Credit/Gift Card workflows and the developer platform. Some highly specialized mapped areas remain candidates for a later consolidation/finalization phase rather than being represented as separate dedicated screens.

## Phase 6 coverage note

Phase 6 closes the specialized mapped gaps that remained after Phase 5, including customer categories/category listing/search results/404/maintenance and admin transactions, payouts, inventory report, marketing report, store settings, checkout settings, shipping settings, tax settings, admin login and admin 404.

The mapped customer/admin surface set is now represented by dedicated routes/views or, where appropriate, by an explicit multi-step operational workflow such as checkout. External gateways, SMTP delivery, third-party webhook receivers and production infrastructure still require environment-specific credentials and live-service testing after deployment.
